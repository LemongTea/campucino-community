# Campucino YouTube Cookie Exporter

## Install locally in Chrome

1. Buka `chrome://extensions`.
2. Aktifkan **Developer mode**.
3. Klik **Load unpacked**.
4. Pilih folder `browser-extension/youtube-cookie-exporter` dari project ini.
5. Buka YouTube dan login menggunakan profil Chrome yang sama.
6. Klik ikon extension, lalu klik **Download youtube-cookies.txt**.

File yang dihasilkan adalah format Netscape yang bisa dibaca yt-dlp. Simpan file tersebut di komputer lokal dan jangan commit atau kirim ke orang lain.
